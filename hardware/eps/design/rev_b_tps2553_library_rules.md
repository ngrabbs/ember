Outline note excludes mold flash/protrusion up to 0.25 mm per side; conservatively allow that addition in courtyard sizing. Exact TI example pad centers are the table above, row separation 2.60 mm, pitch 0.95 mm.

- Six numbered SMD roundrect copper/paste/base-mask pads: size **1.10 × 0.60 mm**, R=0.05 (`roundrect_rratio=1/12`), rotation 0, layers F.Cu/F.Paste/F.Mask, no drills. Copper and paste each form six disconnected regions. The p36 stencil example uses the same six lands with 0.125 mm stencil; this is source geometry, not production stencil qualification.
- Six **blank-number** F.Mask-only roundrect apertures, same centers, size **1.20 × 0.70 mm**, R=0.10 (`roundrect_rratio=1/7`). Their union with base pad mask implements an explicitly chosen **+0.05 mm nominal NSMD expansion** despite absent per-pad native margin API. TI p35 says **0.07 mm MAX around** for preferred NSMD, not MIN; solder-mask-defined alternative says 0.07 MIN and is not selected. No numbered mask-only objects. The saved board's inherited pad/footprint mask margin must be queried and rendered: effective union must remain +0.05 nominal and never exceed TI's +0.07 limit. ## Circuit boundaries remain open

This shared package candidate does not assign EN/reset/FAULT GPIOs, limits, series resistors, source/output capacitors or net names. Existing CAN candidate calculations are historical screening, not BMS-primary branch sizing.
