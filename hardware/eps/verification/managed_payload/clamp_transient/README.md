# OVP-sense clamp transient sensitivity

2026-10-24. **Nominal subcircuit study; no circuit integration or survival
release.** All 24 LTspice 26.0.2 runs reached the requested 2 ms endpoint.
`analysis.json` checks deck/model/log/raw hashes and extracts full adaptive-trace
metrics; `results.json` and per-case JSON retain the original run results.

| Screen | Result |
| --- | --- |
| Highest OVP, no added filter | 3.90601 V |
| Highest OVP, added 1 nF | 3.74600 V |
| Lowest OVP across all cases | −5.942 mV |
| Reference bias absolute peak | 3.421 mA |
| OVP within imposed −0.3..5.5 V absolute window | 24/24 cases |
| OVP within full 0..4 V operating window | 12/24 cases |

Cold-start cases have millivolt negative excursions; do not relabel them as
full operating-window passes. The imposed constant 150 nA input sink remains
on at zero source, so this is also a limitation of the simplified pin model.
The reference node reaches 5.008 V in this macro during a transient; it is not
an ideal fixed 2.5 V source. No reference dynamic-rating acceptance follows.

The matrix uses 8.4→35→8.4 V and 0→35→0 V sources, −40/25/+85 °C simulator
settings, 0/1 nF added OVP capacitance and imposed 0.9/1.2 V diode envelopes.
Each source edge is 1 ns; fault duration is 0.5 ms. Nominal divider/bias values,
0.5 pF source feedthrough, 2 nH lead inductances and 5 pF pin capacitance are
study assumptions, not measured parasitics or accepted source bounds.

With 1 nF, first OVP crossings of the 1.176..1.224 V threshold range occur
0.233..0.363 µs after the warm rising source edge and 2.634..2.767 µs after the
cold rising edge in these cases. These omit eFuse detection, gate and output
response. Filtering trades overshoot for delay; no downstream protection
timing pass is claimed. Retain nominal C1406=1 nF as a development candidate,
with exact MPN, tolerance, temperature and coupled protection checks open.

TI's [SNOM541 download](https://www.ti.com/lit/zip/SNOM541) provides an explicitly
unencrypted LM4040_NC2P5 transient macro, Final 1.00, 10APR2013, PSPICE16.
The preserved `.lib` is byte-identical to its ZIP member; hashes are recorded
in `analysis.json`. Its original copyright/disclaimer and line endings remain.
TOL=0 is nominal. Package-specific startup and PVT validation are not supplied
by this experiment. LTspice warns that PBSW/UCRIT/DIOMOD are ignored in the
unused Menable declaration; no M instance uses that model. Original warnings
remain in every log. This is not vendor-certified simulator compatibility.

The diode is a behavioral instantaneous forward envelope plus 2 pF, **not**
the BAS116H vendor model. Its cold VF, reverse recovery, leakage, production
spread and real interconnect are not proven. TPS2663, the main MOSFET, output
load, source impedance and essential rails are absent. Consequently these
runs cannot establish cutoff, SOA, reverse interruption or healthy-rail survival.

`clamp_edges.png` and its PDF were actually inspected: four panels show rise
and return edges for the warm +85 °C and cold −40 °C imposed 1.2 V cases, with
and without filtering. Full-trace maxima, not graph limits or sparse CSVs,
determine the table above. CSVs retain all samples close to edges and every
200th background sample; `.raw` files are ignored and regenerated by simulation.
`warm_cap0_vf0p9_t25` is a preserved initial single-edge attempt, excluded from
the 24-case matrix. Logs/model bytes may retain vendor/simulator whitespace.

Reproduce with `python3 run.py --matrix` using LTspice at the path in the
script, then `python3 analyze.py` with NumPy/Matplotlib. Run caching requires
matching deck/model hashes and a completed prior status; analysis requires
the raw traces. No native KiCad file is written by either script.
