## Method and checks

Run the bundled Python with `check_calculator.py --source /tmp/ember-UCC3302X-CALC-V1.xlsx`. The script independently translates the selected Sheet2 charge/duty recurrence and Tonmax burst formula into numeric Python. It matches all640 shipped default Q/S/I cells within1.2e-13 absolute, default rise time625 µs, and default burst duration1.7839181258 µs. This establishes agreement with those source calculations, not independent validation of TI's empirical model or an Excel recalculation result.

Inputs!C13:C20 define input/output voltage, zero-/5 V-bias capacitance, ESR, load type/magnitude and load threshold. C21 takes Sheet2!Y2 against a16 ms limit; C23 takes Tonmax!O2 against a13 µs limit. The script preserves the listed Vin-bin approximate VLOOKUP for burst current without inventing interpolation. Sheet2!U4 includes a self-reference/forward LOOKUP; it is unnecessary for these translated cases because V4=1 makes W4=1. This narrow translation does not claim to evaluate that unrelated/circular expression.

The sensitivity grid uses Vin3.0/3.1/3.3 V, zero-/5 V-bias capacitance pairs22/10.5,33/16 and47/33 µF, with constant-current startup loads13/50/100 mA applied from0 V. These pairs are scenario inputs, not qualified limits for selected capacitors. The higher startup loads screen the additional post-regulator capacitor charging;13 mA is the provisional steady isolated-stage allocation. The separate nominal LT3014 model draws about45.8 mA peak at startup with10 µF effective output capacitance, but does not provide a guaranteed maximum for the actual device.

All27 translated cases reach the selected5 V regulation point in650–3075 µs, before the calculator's16 ms cutoff. The13 mA steady-state translated burst duration spans about2.17–8.16 µs, below its13 µs condition, with calculated ripple43.6–48.9 mV. These values are model estimates; they are **not** datasheet maxima and must not replace the75 mVpp/25°C/5 V qualification or actual ripple measurement. The source's internal cold-current data rows likewise cannot be promoted to a guaranteed cold power rating.

## Current design decisions and remaining gates

Prefer UCC33020 5.0 V (SEL=VCC) plus [LT3014 post-regulator](../lt3014_screen/README.md). The fixed intermediate output and local raw return remain electrically distinct from system +3V3/GND; preserve the shunt boundary. The steady/post-regulator and converter startup calculations are separate and do not form a coupled simulation.

For high-frequency UCC bypasses, select **TDK CGA3E2X7R1H153K080AA**,15 nF±10%,50 V,X7R,0603,−55..125°C, using the [manufacturer part record](https://product.tdk.com/en/search/capacitor/ceramic/mlcc/info?part_no=CGA3E2X7R1H153K080AA). It is listed for production; the commercial C1608 predecessor is not preferred for new designs. These nominal ratings match the UCC reference values. Procurement and actual parasitics remain separate. Existing qualified-for-development Murata GRM32ER71E226KE15L22 µF/25 V/X7R1210 and TDK CGA5L1X7R1H106K160AC10 µF/50 V/X7R1206 are bulk-capacitor candidates, not newly verified bias/temperature bounds. The LT output target remains ≥4.7 µF effective; current models include10 µF.

Complete exact capacitance/ESR envelopes, essential-rail input current/inrush and branch-fault containment, UCC arbitrary prebias/repeated UVLO, full-temperature limits and physical thermal/EMC review before closing the circuit qualification. The existing unqualified essential-rail step can dip below3.0 V, so BMS communication cannot be promised through that event. MCU supply-settle/bus-recovery/identity validation remains mandatory. No real EPS source or library is changed by this read-only calculator review; separate approved UCC library work has its own evidence.

## Primary branch containment constraint

The existing [TPS2553-1 CAN branch study](../../controller_rev_b/branch_selection/README.md) is a possible shared component family for isolating a failed BMS power module from essential3V3. Its110–151 mA programmed-limit screen cannot simply be copied with the CAN branch's small downstream capacitance. The UCC's burst current is substantially above its average current. As an **imposed sizing sensitivity**, a0.8 A,8.16 µs input burst behind a110 mA limiter removes about5.63 µC from the local reservoir. The corresponding droops are about0.563/0.171/0.120 V for10/33/47 µF effective input capacitance, before ESR, switch drop or source sag. The0.8 A burst is an engineering scenario, not a guaranteed UCC input-current maximum. This identifies a required coupled limiter/reservoir/startup check; it neither selects a limiter nor closes branch fault containment. Do not add a small current limiter without accounting for this local energy demand and its own turn-on/fault timing.
