## Primary ST pin and reset reconciliation

[ST DS13560 Rev6, February2026](https://www.st.com/resource/en/datasheet/stm32g0b1ke.pdf), Table12 p53: N-package PD0 lead26 is **FT_cs/UCPD2_CC1**; PD3 lead29 is **FT_ds/UCPD2_DBCC2**. Both `_s` pads use VDDIO2 (lead20), presently tied to the same+3V3 as VDD. General reset mode is analog input. **p55 footnote4** warns that reset pull-downs on PD0 and PD2 depend on PD1 and PD3 respectively; disable them through SYSCFG UCPDx_STROBE during startup. PD3 is the DBCC control, not the CC pin carrying that pull-down.

Table55 pp93–94: valid-supply pad leakage is ≤2µA for FT_c and≤4.5µA for FT_d when0<VIN≤VDDIOx; these design-specified values support the proposed5µA planning guard after correct configuration, not unknown-supply/back-power behavior. Conservative CMOS thresholds0.3/0.7VDDIOx apply. Table57 p96 supplies the0.4V sink-output row used by the GPIO screen. Open-drain GPIO mode is available; do not select a UCPD alternate function. See the manufacturer [LL source](https://raw.githubusercontent.com/STMicroelectronics/stm32g0xx-hal-driver/master/Inc/stm32g0xx_ll_system.h): `LL_SYSCFG_DisableDBATT` sets the requested `SYSCFG_CFGR1` strobe bits. Its unmodified local artifact/hash is in `sources.json`.

## Source option and release recommendation

**Protected permitted+5V is worth screening as the primary source before committing the3V3 topology.** It moves converter bursts/short demand away from the MCU/CAN essential3V3 node and offers more voltage headroom; a smaller primary bank may become possible only after a new startup calculation. It also adds a recovery-rail dependency: losing+5V loses BMS telemetry, while autonomous BQ protection remains in the retained raw domain. There is no circular requirement if charger/protector hardware remains autonomous. Keep TPS EN/FAULT pullups at+3V3; UCC enable bias must use its own permitted primary domain. Review control-driven power-off leakage when5V is absent but3V3 remains.

Do not select that alternative from nominal5V alone: verify the downstream protected+5V full normal/fault envelope against UCC3.0–5.5V operation, sequencing, module startup/current allocation and both shared-rail fault paths. Earlier bounded5V protection runs are not an all-condition rail limit. The existing3V3 input study does not prove healthy-load survival under a shared-rail short, and a TPS2µs typical5V response is not a guaranteed3.3V fault bound.
