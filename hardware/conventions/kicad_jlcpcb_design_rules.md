# KiCad Design Rules & Impedance — JLCPCB Constraints

**Scope:** every PCB migrated to or started in KiCad (comms transceiver
first). JLCPCB standard 4-layer 1.6 mm FR4 (`JLC04161H-7628`) unless stated
otherwise.
**Owner:** hardware lead.
**Status:** living document — update when JLCPCB changes stackups/capabilities.

This is the single source of truth for JLCPCB design rules on this project:
the target numbers, the reasoning behind them, and where each one goes in
KiCad. Board design is KiCad-only.

---

## 0. Quick start (the morning refresher)

You want: JLCPCB 4-layer stackup set, plus certain traces forced to 50 Ω.
KiCad splits that into **stackup → calculator → net class**. The click-path:

1. **`File → Board Setup → Physical Stackup`** — set 4 layers / 1.6 mm, enter the
   `JLC04161H-7628` dielectric heights + εr (§2). KiCad has **no JLCPCB plugin**,
   so you type them.
2. **Get the 50 Ω width** — easiest is **JLCPCB's online impedance calculator**
   (jlcpcb.com/impedance): pick `JLC04161H-7628`, L1, 50 Ω → it gives the width.
   Should reproduce our **~0.358 mm** (§3). (KiCad's own calc: `Tools →
   Calculator Tools → Transmission Line`.)
3. **`Board Setup → Net Classes`** — make a class **`RF`**, set its **Track
   Width** to that value. Assign nets by pattern **`RF_*`** (§4). Our net-naming
   convention makes this one line.
4. **(Recommended) Custom rule** so DRC actually flags off-width RF traces (§5.3).
5. **Order:** tell JLCPCB "impedance controlled" at checkout — it's not in the
   Gerbers (§6).

That's the whole thing. Details below.

---

## 1. The one capability gap to know about

KiCad has no live impedance-profile ↔ stackup binding. You compute the 50 Ω
width once against the stackup (§3) and pin it into a net class (§4). If JLCPCB
revises the stackup, **nothing warns you** — recompute by hand. The §5.3 custom
rule is how you get DRC to at least flag traces that drift off the width you
chose.

Everything else — constraints, net classes, pre-defined sizes — is entered once
in `Board Setup` and travels between boards via a template project (§13).

## 2. Stackup — `Board Setup → Physical Stackup`

1. First set the layer count: `Board Setup → Board Editor Layers` → **4 copper
   layers**, board thickness **1.6 mm**.
2. `Board Setup → Physical Stackup` → enter `JLC04161H-7628` per-dielectric
   thickness, εr (Epsilon R), loss tangent, and copper weight.

**Get the live numbers from JLCPCB's stackup / impedance page** — they are the
authority and occasionally revise. The impedance-critical dimension is the
**L1 ↔ L2 prepreg** (the ground plane directly under your top-layer RF traces):

Measured values for `JLC04161H-7628`, read from the KiCad stackup in
[gsuberland/jlcpcb_autogenerated_stackups](https://github.com/gsuberland/jlcpcb_autogenerated_stackups):

| Layer | Function | Copper | Dielectric below | εr |
|---|---|---|---|---|
| L1 (top) | Signal / RF | 0.035 mm | **prepreg 0.2104 mm** (Nan Ya NP-155F 7628) ← sets 50 Ω width | **4.4** |
| L2 (inner) | **Solid GND plane** | 0.0152 mm | core 1.065 mm (Nan Ya NP-155F) | 4.43 |
| L3 (inner) | Power islands / slow sig | 0.0152 mm | prepreg 0.2104 mm | 4.4 |
| L4 (bottom) | Signal / GND pour | 0.035 mm | — | — |

Solder mask is **0.01524 mm, εr 3.8** top and bottom. That thickness is
JLCPCB's "Coating Above Trace" (C2, 0.6 mil) — the figure that matters for a
trace's mask loading, not their "Coating Above Substrate" (C1, 1.2 mil). Mask
over a microstrip raises the effective dielectric constant and pulls Z₀ down,
which is why JLCPCB quotes 0.358 mm *with* mask.

**Loss tangent** is not published by JLCPCB. Both prepreg and core are Nan Ya
NP-155F, so 0.02 is used for all three dielectrics — the value their generated
stackup carries for the core. At 437 MHz over a short trace the loss is
negligible; the point is that 0 is not a physical value for FR4.

**Copper finish:** ENIG on the comms board — flatter than HASL under the 0402
resonators and the SMA launch.

> **Why 7628 and not 3313.** JLCPCB publishes several 4-layer 1.6 mm
> stackups. `7628` puts 0.2104 mm of prepreg between L1 and L2; `3313` puts
> 0.0994 mm. The 50 Ω width follows directly from that height, so 7628 gives
> ~0.358 mm and 3313 would need roughly half. **0.358 mm is only correct for
> 7628** — if you change stackup, recompute. An earlier revision of the
> superseded Altium doc listed 3313's dielectrics under the 7628 name; that
> error is the reason this section now carries the measured numbers.

Keep **L2 a solid, unbroken GND plane** under all L1 RF traces — that's the
single biggest SI win (see `../comms/design/rf_layout_guidelines.md`).

## 3. 50 Ω trace width

Two ways to get the number; use whichever, they should agree within a few µm:

**A. JLCPCB online impedance calculator (recommended — their exact stackup).**
jlcpcb.com/impedance → choose `JLC04161H-7628` → layer **L1 (top, microstrip)**
→ target **50 Ω single-ended** → read off the width. This is exactly what the
Altium JLCPCB plugin did internally, so it's the most faithful to what gets
fabbed. Expected: **≈ 0.358 mm** with solder mask.

**B. KiCad built-in.** `Tools → Calculator Tools → Transmission Line` (or the
standalone **PCB Calculator** app):
- Model: **Microstrip** if the RF trace has ground only *below* (L2); **Grounded
  Coplanar Waveguide (GCPW)** if you also flood ground on both sides of the
  trace on L1 (then the ground-gap matters too). **The comms board is
  microstrip** — see the decision and the 1.1 mm pour standoff in
  [`../comms/design/rf_layout_guidelines.md`](../comms/design/rf_layout_guidelines.md).
- Inputs: εr ≈ 4.4, substrate height h = L1→L2 prepreg (~0.2 mm), copper
  thickness t (0.5 oz ≈ 17.5 µm), Z0 = 50 Ω, freq ≈ 437 MHz → **solve for W**.
- Add solder-mask loading if the model supports it (drops W slightly).

For **diff pairs** (payload carrier: PCIe/USB/CSI), use the **coupled**
microstrip model to get width **and** gap, then enter both in the net class.

## 4. Net classes & assignment — `Board Setup → Net Classes`

Define classes with per-class Clearance / Track Width / Via Size / Diff Pair
Width+Gap, then assign nets by **pattern** (lower half of the Net Classes
dialog). Our [`net_naming.md`](net_naming.md) prefixes make assignment trivial:

| Net class | Pattern(s) | Track Width | Clearance | Notes |
|---|---|---|---|---|
| `Default` | (everything else) | 0.2 mm (8 mil) | 0.2 mm | digital signal default |
| `RF` | `RF_*`, `LO_*` | **0.358 mm** (50 Ω, from §3) | per RF layout guide | L1 only, solid GND under |
| `PWR` | `+3V3`, `+5V` | 0.5 mm (~20 mil) | 0.2 mm | low-current rails |
| `PWR_HIGH` | `VBAT`, high-current rails | 1.27 mm (50 mil) | 0.25 mm | outer layers only |
| `DIFF_*` | per board (`DP_CSI`, `DP_PCIE`, `DP_USB`) | per impedance target | per target | Diff Pair W+G fields |

Assignment example (Net Classes dialog → patterns): `RF_*` → `RF`. Because RF
nets are named `RF_TX_MMIC_OUT`, `RF_RX_LNA_OUT`, etc., that one pattern catches
them all. Verify membership in the **Net Inspector** (Appearance panel) or by
coloring nets by class.

## 5. Design rules — `Board Setup → Design Rules`

### 5.1 Constraints (global minimums) — mirror the Altium §2 cheat-sheet

| Constraint (KiCad Constraints page) | Value | Altium equiv |
|---|---|---|
| Minimum track width | 0.2 mm | 8 mil default |
| Minimum clearance | 0.2 mm | 8 mil |
| Minimum via diameter | 0.6 mm | 24 mil pad |
| Minimum via drill / hole | 0.3 mm | 12 mil |
| Minimum annular width | 0.15 mm | 6 mil/side |
| Minimum through-hole (PTH) | 0.3 mm | — |
| Hole to hole clearance | 0.6 mm | 0.6 mm |
| Copper to edge clearance | 0.3 mm | 12 mil |
| Copper to hole clearance | 0.25 mm | 10 mil |
| Silk min line width (Text & Graphics defaults) | 0.15 mm | 6 mil |
| Silk text height (refdes) | 0.8 mm; warnings 1.0 mm | 32 / 40 mil |
| Solder mask min web/sliver (Solder Mask/Paste page) | 0.127 mm | 5 mil |
| Solder mask expansion | 0.1 mm | 0.1 mm |

Full reasoning for every number: §7–§12 below.

### 5.2 Pre-defined track/via sizes
`Board Setup → Design Rules → Pre-defined Sizes` — add the RF width (0.358 mm)
and the power widths (0.5 / 1.27 mm) as pickable track sizes, and the standard
via (0.6 / 0.3 mm) so you can switch on the fly while routing.

### 5.3 Custom rule — enforce the 50 Ω width band (the Altium "scoped rule")
KiCad's **Custom Rules** (`Board Setup → Design Rules → Custom Rules`, saved to
`<board>.kicad_dru`) are the closest thing to Altium's scoped width rule and
give you **DRC-flags-off-width** behavior. Add:

```
(version 1)

(rule "RF 50ohm microstrip width"
  (condition "A.NetClass == 'RF'")
  (constraint track_width (min 0.35mm) (opt 0.358mm) (max 0.37mm)))
```

Now any `RF`-class trace routed outside 0.35–0.37 mm throws a DRC violation —
your safety net against fat-fingering the RF width. Adjust the band to whatever
the JLCPCB calc gives for the fabbed stackup. (Do the same per diff-pair class
with `diff_pair_gap` / `track_width` constraints if desired.)

## 6. Ordering controlled impedance at JLCPCB

**Impedance intent is NOT in the Gerbers.** At the JLCPCB order
page:
- Select the **impedance-controlled** option and specify stackup `JLC04161H-7628`.
- Tolerance ±10 % standard (±5 % costs more).
- Impedance **test report** ~$5–15/order: **skip for dev/v0.x runs, order for
  flight builds** (per Altium doc §8).
- 4-layer minimum for any controlled impedance (impossible to control on 2-layer).

Order controlled impedance for the **comms board** (50 Ω microstrip) and the
**payload carrier** (PCIe/USB/CSI diff pairs).

## 7. Track width and current capacity

### 7.1 Signal traces
0.2 mm (8 mil) is the project default for anything under ~200 mA. JLCPCB's
process minimum is 0.127 mm (5 mil); the default pads that for yield.

### 7.2 Power traces

On `JLC04161H-7628` the copper weights are **not** the same on every layer:

| Layers | Weight | Finished thickness |
|---|---|---|
| L1, L4 (outer) | **1 oz** | 0.035 mm |
| L2, L3 (inner) | **0.5 oz** | 0.0152 mm |

Outer layers finish thicker because through-hole plating deposits copper on
top of the base foil; inner layers are etched from foil and never plated, so
they stay at their base weight.

**Route power on outer layers and use the 1 oz column.** The 0.5 oz column is
only for the case where a power net has to cross on L2/L3 — and see the
doubling rule below before doing that.

Widths assume ≤ 10 °C temperature rise.

| Current (continuous) | Width (1 oz outer) | Width (0.5 oz outer) |
|---|---|---|
| < 200 mA | 0.2 mm (8 mil) | 0.2 mm |
| 500 mA | 0.38 mm (15 mil) | 0.5 mm (20 mil) |
| 1 A | 0.64 mm (25 mil) | 0.9 mm (35 mil) |
| 2 A | 1.27 mm (50 mil) | 1.8 mm (70 mil) |
| 3 A | 1.8 mm (70 mil) | 2.5 mm (100 mil) |
| 5 A | 2.8 mm (110 mil) | 4.1 mm (160 mil) |
| `VBAT` (~2 A typ, 4 A peak) | 1.5 mm (60 mil) outer, with pour return | |

Above ~2 A on **inner** layers, double the outer-layer width — inner layers
are both thinner (0.5 oz) and dissipate heat poorly. Better practice: route power on outer layers, use pours
for distribution, reserve inner layers for ground and signal.

When in doubt use Saturn PCB Toolkit or
[4pcb.com/trace-width-calculator](https://www.4pcb.com/trace-width-calculator.html)
(IPC-2221 based).

## 8. Vias

JLCPCB charges no per-via fee but limits minimums by process tier. Stay on the
standard tier.

### 8.1 Standard via

| Property | Value | Notes |
|---|---|---|
| Drill | **0.3 mm** | Standard tier; smaller incurs a surcharge |
| Outer pad diameter | **0.6 mm** | Gives 0.15 mm annular ring per side |
| Annular ring | **0.15 mm/side** | 50 % above JLCPCB's 0.1 mm minimum |
| Aspect ratio | drill : thickness ≤ 1:8 | 0.3 mm in 1.6 mm is 1:5.3 — fine |

In KiCad: `Board Setup → Design Rules → Pre-defined Sizes` → via 0.6/0.3 mm.

### 8.2 Power vias (≥ 1 A through a layer transition)
Use **multiple parallel vias** rather than one large via — paralleling drops
effective inductance roughly as 1/N and spreads the current.

| Current through transition | Vias |
|---|---|
| < 500 mA | 1 (standard via is good for ~1.5 A continuous) |
| 500 mA – 1.5 A | 2 |
| 1.5 A – 3 A | 4 |
| 3 A – 5 A | 6+ |

### 8.3 Tented / open / filled

| Treatment | When | Cost |
|---|---|---|
| **Tented** (mask over via) | Default for signal and most power vias | none |
| **Open / exposed** | Test points, debug, vias under fiducials | none |
| **Plated Over Filled Via (POFV)** | Via-in-pad on QFN/BGA ground pads where solder theft is a problem | **+$3–5/order** |

See [`../comms/design/rf_layout_guidelines.md`](../comms/design/rf_layout_guidelines.md)
for the 0402 dogbone-vs-via-in-pad discussion. Short answer: not worth the
surcharge for dev runs; yes for flight builds.

## 9. Clearances

`Board Setup → Design Rules → Constraints`, plus per-class overrides in
`Net Classes`.

| Clearance type | JLCPCB min | **Project default** |
|---|---|---|
| Track/pad/via to track, different nets | 0.127 mm | **0.2 mm** |
| Pad to pad, different nets | 0.127 mm | **0.2 mm** |
| Copper pour to track, different net | 0.127 mm | **0.25 mm** |
| Copper to board edge | 0.2 mm | **0.3 mm** (0.5 mm on the comms board) |
| Diff pair to other trace | 0.127 mm | **3 × W** (see the board's layout guide) |
| High-voltage (> 50 V) | per IPC-2221 | Tier B uncoated, sea level |

High-current rails like `VBAT` are still low **voltage** — the 0.2 mm default is
plenty. Don't over-think it.

## 12. When to deviate

The project defaults deliberately pad JLCPCB's minimums for yield. Deviate when:

- **Moving to JLCPCB's advanced tier** (0.09 mm) for a dense flight board that
  cannot otherwise be routed. Update this doc with the new defaults.
- **A component demands tighter** — a 0.4 mm pitch BGA needs ~0.1 mm traces to
  escape. Use a higher-priority custom rule scoped to that area and document the
  exception in the board's layout guide.
- **High-voltage clearance** is required (> 50 V working). Use IPC-2221
  Table 6-1 and add a scoped clearance rule.

Don't deviate to save space. If the board is too dense for the project
defaults, the answer is almost always **a bigger board, not tighter rules**.

## 13. Reuse across boards (KiCad has no `.RUL` import)

KiCad has no single-file rules export/import. To reuse:
- **Custom rules:** copy the `.kicad_dru` file into the next project (or keep a
  shared `jlcpcb_baseline.kicad_dru` in this folder and copy it in).
- **Constraints + net classes:** fastest is to **start new boards from a
  template `.kicad_pro`/`.kicad_pcb`** that already has the stackup, constraints,
  net classes, and pre-defined sizes set. Save one once the comms board is
  dialed in and reuse it.
- **Stackup:** re-enter (or copy the stackup section of the template board).

## 14. New-board checklist (KiCad)

- [ ] `Board Editor Layers` → 4 layers, 1.6 mm
- [ ] `Physical Stackup` → enter `JLC04161H-7628` (verify against JLCPCB live page), solid L2 GND
- [ ] Get 50 Ω width (JLCPCB impedance calc or KiCad Transmission Line) → record it
- [ ] `Net Classes` → create `RF` / `PWR` / `PWR_HIGH` / `DIFF_*`, set widths (RF = the 50 Ω number)
- [ ] `Net Classes` patterns → `RF_*`→`RF`, `+3V3`/`+5V`→`PWR`, `VBAT`→`PWR_HIGH`
- [ ] `Design Rules → Constraints` → enter §5.1 minimums
- [ ] `Design Rules → Pre-defined Sizes` → RF/power widths + standard via
- [ ] `Design Rules → Custom Rules` → paste §5.3 RF-width rule (+ diff-pair if needed)
- [ ] Run DRC on empty board — confirm no false positives
- [ ] At order time: JLCPCB → impedance controlled, `JLC04161H-7628`, report for flight only
