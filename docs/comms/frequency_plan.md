# Frequency plan

[Topic guide](README.md)

The [single-antenna integration record](../../hardware/comms/design/single_antenna_integration.md)
documents 437 MHz TX / 435 MHz RX, half duplex on one UHF antenna. Earlier VHF RX
notes describe a different design. These are documented design frequencies, not
proof of a coordinated or authorized operating allocation; final coordination
status still needs an owning record.
