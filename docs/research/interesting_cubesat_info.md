# CubeSat projects and resources

[Research references](README.md)

Background links for design research; descriptions are research notes, not EMBER
requirements or verified supplier recommendations.

| Project | Useful context | Resources |
|---|---|---|
| EQUiSat — Brown | Low-cost student 1U, commercial parts, LED beacon; code and CAD | [Project](https://www.brownspace.io/equisat.html), [GitHub](https://github.com/BrownSpaceEngineering) |
| Phoenix — Arizona State | Student mission documentation, team organization, and lessons learned | [Documents](https://phxcubesat.asu.edu/resources/documents) |
| GASPACS — Utah State | Student 1U inflatable-boom attitude experiment; Raspberry Pi Zero and comms documentation | [Project](https://www.usu.edu/physics/gas/projects/gaspacs) |
| SBUDNIC — Brown / NRC Italy | Commercial-parts 3U, Arduino/AA-battery approach, reproducible hardware | [Project](https://www.sbudnic.space) |
| EIRSAT-1 — University College Dublin | 2U mission; gamma-ray, thermal-coating, and software-radio payloads; integration and verification | [Paper](https://arxiv.org/abs/2010.10425) |
